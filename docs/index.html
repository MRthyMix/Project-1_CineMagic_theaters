CineMagic Theater

A command-line movie theater I wrote in C++: buy tickets, pick your seats, order snacks, and get a receipt. The program is ported to JavaScript here so you can run it in a console window right in your browser.

Inside the program

      
I built this when I was first learning to code. It runs entirely in the command prompt: menus are drawn with text, choices go through switch statements, and every movie's seats and ticket counts are randomized when the program starts.

    

    
    
      
  • A struct Ticket and a vector<Ticket> hold every line of the order, from movie tickets to popcorn.
    • 
      
  • A 3-D array, seats[5][5][6], tracks open and taken seats for each of the five movies.
    • 
      
  • readInt() asks again when someone types letters instead of a number.
    • 
      
  • The receipt adds 7% sales tax, and ofstream writes the tickets to ticket.txt.
